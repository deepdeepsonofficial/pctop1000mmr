# Листва — дневник ухода за растениями

Сайт-справочник и личный дневник для любителей комнатных растений.

## Запуск
Откройте `index.html` в браузере или запустите проект через Live Server в VS Code.

## Возможности
- Справочник из 9 растений с фотографиями, поиском и фильтрацией.
- Личный сад с начальными растениями, отметкой полива и удалением.
- Дневник ухода с примерами записей и добавлением новых.
- Профиль: имя, почта, телефон, город и информация о себе.
- Светлая и тёмная темы.
- Экспорт и импорт данных в JSON.

## Хранение
Backend и база данных не используются. Данные хранятся в localStorage текущего браузера. Фотографии загружаются с Unsplash, поэтому для них нужен интернет. Профиль не является серверной регистрацией.
