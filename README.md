# pctop1000mmr

Проект компьютерного клуба: страницы бронирования, ПК и PlayStation.

## Структура
- `booking.html` — бронирование
- `pc.html` — информация о ПК
- `playstation.html` — информация о PlayStation
- `style.css` — стили
- `script.js` — JavaScript
- `assets/` — изображения и игровые обложки
